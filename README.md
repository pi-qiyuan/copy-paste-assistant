# Copy Paste Assistant

**Copy Paste Assistant: Smart Snippets & Instant Form Filling**  

---

Tired of repeatedly typing addresses, email templates, code snippets, or complex form data? **Copy Paste Assistant** is a lightweight, privacy-focused productivity tool designed to manage your common snippets through intelligent sensing and minimalist interaction. Achieve a "zero-distance" filling experience without ever taking your eyes off the input area. 

Whether you are filling out repetitive forms, responding to customer inquiries, or managing development snippets, this extension streamlines your entire workflow.

---

## 🌟 Core Features

* **✨ Smart Floating Assistant**: When your cursor enters a web input field, a translucent assistant icon (📋) automatically appears in the bottom-right corner. Click it to call up your "Recently Used" list for instant insertion without switching focus.

* **🖱️ Enhanced Context Menu**:
    * **Quick Save**: Select any text on a webpage and right-click to save it to the assistant instantly. It automatically handles line breaks and extra spaces.
    * **Hierarchical Insertion**: Right-click in any editable area to browse and insert content via a "Category -> Item" menu structure.

* **🕒 Dynamic "Recently Used"**: The system automatically tracks and pins your 10 most recent items. This list is synced across the extension popup, context menu, and floating widget.

* **🗂️ Management & Categorization**:
    * **Note System**: Add custom names (notes) to your snippets.Titles are displayed in bold for quick identification among similar items.
    * **Flexible Categories**: Create custom categories with a "Pin (📌)" feature. If a category is deleted, items are safely moved to the "Default Category."

* **🔍 Real-time Global Search**: A minimalist search entry that matches names and content across all categories with keyword highlighting.
* **💾 Local Privacy & Security**:
    * **Offline Operation**: All data is stored locally. No internet connection or servers are used, ensuring absolute privacy.
    * **Readable Backups**: Supports importing and exporting via plain text files. The format is easy to read and edit, facilitating seamless migration between devices.

* **🛠️ Deep Framework Compatibility**: Uses native JavaScript to trigger `input` events, ensuring perfect compatibility with React, Vue, Angular, and `contentEditable` rich text editors.

## 📖 Instructions

1. **Add Snippets**: Click the extension icon to add your first piece of text. Choose a specific category or use the "Default" one.
2. **Quick Fill**: Focus on any input field on a webpage. Look for the floating "📋" icon or right-click the field.
3. **Insert**: Select the item you want to fill. It will appear immediately at your cursor position.
4. **Save from Web**: Simply highlight text on any page, right-click, and select "Add to Assistant."

---

## 🎨 UI/UX Design Philosophy

* **State Memory**: The extension automatically remembers your last used category so it's ready as soon as you open it.
* **Focused Interaction**: Search, addition, and management interfaces use mutually exclusive expansion logic to minimize visual noise.
* **Real-time Feedback**: All operations (copying, inserting, deleting) include clear visual cues and secondary confirmation for safety.
